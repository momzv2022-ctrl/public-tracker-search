Search the public torrent indexes from one URL

Copy one file, paste it into a free Cloudflare Worker, and you get a URL and a key that search 10 public indexes at once — names, sizes, seeders and magnet: links, in one list, for qBittorrent or any app that speaks HTTP.

This page makes no network request at all, and the browser is told to refuse one. Your key is made here, in your browser, and written into your copy of the file — nowhere else. There is no public copy of this: the only URL that exists is the one you make.

1. Copy the code

Your key

The key is already inside the file, on the API_KEY line near the top. You do not need to write it down: the Worker shows it to you once it is running.

2. Put it on Cloudflare

  1. Sign in at dash.cloudflare.com (free, no card; an email address and a password). Open Workers & Pages, press Create, choose Start with Hello World, and press Deploy.
  2. Press Edit code. Select everything in the editor, delete it, paste the code from above, and press Deploy.

3. Open it

Open the Worker's address — the Visit link, or the workers.dev URL on its page. It shows your URL and your key, ready to copy into your app, and a button that runs a real search so you can see it work.

Anyone who can open that address can read the key, so keep the address to yourself; the page tells you how to hide the key once your app has it. To change the key, copy the code again with a new one and paste it over the old.

Use it

qBittorrent: the search plugin takes your URL and key on its first two lines. View → Search Engine, then in the Search tab Search plugins → Install a new one → Local file.

Anything else: GET your-url/api/v1/search?q=… with the key in an X-API-Key header. Every row has a name, a size, seeders, leechers and a magnet. The full API, and how to point an app that already talks to a Unified Torrent Search Interface at this, is in the README.

What this is. One readable file with no dependencies, run for free by Cloudflare. It asks the indexes your question and merges the answers, in the same API as the Unified Torrent Search Interface. Source and documentation: momzv2022-ctrl/public-tracker-search.

Check it before you trust it. The file before your key goes in is worker.js on this site, version 0.1.1, SHA-256 4eec920d9b7bbd905d1c7f4a98da1a348008066f676e7683d4fb549a51372916. Search it for fetch(: the only things it ever contacts are the indexes in the table above and this site's feed.
